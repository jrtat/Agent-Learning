# 正在使用的MCP服务器

> 请允许我将其按照实际用途将他们归类。

## 通用

### ffmpeg-skill

> Readme: https://github.com/kajisho5/ffmpeg-skill#readme

介绍：让 DSH 能使用本机 ffmpeg 来处理音视频文件（有一点需要注意，其本身既可作为 skill，也可作为 mcp）。

PS：ffmpeg-skill 里面的 mcp__ffmpeg__caption 这个工具会尝试 import faster_whisper
其中 faster-whisper 是 OpenAI 语音识别模型 Whisper 的一个高性能重实现版本，专为在生产环境中高效运行而设计。
在本机的 Python 环境中安装相应的库（faster_whisper）并备好模型（有多规格的如 small、medium），这个工具就会自动调用它。

###  yt-dlp-mcp

> Readme: https://github.com/kevinwatt/yt-dlp-mcp#readme

介绍：让 DSH 能够使用本机的 yt-dlp 把 B 站或油管等流媒体的视频下载到本地。

### playwright-mcp

> Readme: https://github.com/microsoft/playwright-mcp#readme

介绍：让 DSH 能直接操控浏览器。
