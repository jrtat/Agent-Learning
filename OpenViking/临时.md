

### 第四层：索引与检索层

OpenViking 的检索不只有**向量搜索**，还可能结合：

- **语义搜索**；
  
- **关键词搜索**；
  
- **URI 和目录浏览**；
  
- **文件读取**；
  
- **目录摘要**；
  
- **按层次递归展开**；
  
- **记忆、资源和技能的分类检索**。

### 第五层：服务与客户端层

当前部署可以抽象为：

```text

DSH
 └── OpenViking Memory Plugin
      └── OpenViking Client/MCP
           └── OpenViking Server
                ├── 数据存储
                ├── 向量索引
                ├── Embedding 服务
                └── VLM/LLM 服务

```

当前服务端运行在 Docker 容器中：

```text

容器名：openviking

端口：1933

```

DSH 通过客户端配置和用户密钥访问 OpenViking。
